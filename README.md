# Shoply — Next.js E-Commerce

Full-stack storefront with persisted products, real orders, Google sign-in, and an admin dashboard.

## Stack

- **Next.js 16** (App Router, Server Components, Server Actions)
- **Tailwind CSS v4**
- **Prisma 6** + **PostgreSQL**
- **Auth.js v5** (NextAuth) — Google provider, database sessions
- **Zustand** — cart state (localStorage)
- **Lucide React** — icons

## Routes

| URL | Page |
|---|---|
| `/` | Homepage with featured products |
| `/products` | Product listing + filter/sort |
| `/products/[id]` | Product detail + related |
| `/cart` | Shopping cart |
| `/checkout` | 4-step checkout — creates real `Order` |
| `/checkout/success?orderId=…` | Confirmation with order summary |
| `/login` | Google sign-in |
| `/admin` | Product CRUD (admin only) |
| `/admin/dashboard` | KPIs, 30-day revenue chart, top products, low stock |
| `/admin/orders` | All orders + status update |

## Local Setup

```bash
# 1. Install
npm install

# 2. Configure env
cp .env.example .env.local
# fill in: DATABASE_URL, NEXTAUTH_SECRET (openssl rand -base64 32),
#          NEXTAUTH_URL=http://localhost:3000,
#          GOOGLE_CLIENT_ID/SECRET, ADMIN_EMAILS=you@example.com

# 3. Migrate + seed
npx prisma migrate dev --name init
npx prisma db seed

# 4. Dev
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Google OAuth setup

1. Create OAuth client at https://console.cloud.google.com/apis/credentials
2. Authorized redirect URIs:
   - `http://localhost:3000/api/auth/callback/google`
   - `https://<your-render-url>/api/auth/callback/google`
3. Copy client ID/secret into env vars.

## Admin role

Any user whose email is in `ADMIN_EMAILS` (comma-separated) becomes admin on next sign-in. The role is also persisted to the DB.

## Deploy to Render

The `render.yaml` blueprint provisions a free Postgres + web service. After connecting the repo:

1. Set non-secret env vars Render asks for (`NEXTAUTH_URL`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `ADMIN_EMAILS`).
2. First deploy will run `prisma migrate deploy` + `prisma db seed` automatically.
3. `NEXTAUTH_SECRET` is auto-generated by Render.
